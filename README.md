# 🚍 TransitIQ — Smart City Public Transport Optimizer

An interactive data analytics dashboard designed to explore public transport performance, identify congestion patterns, and predict delays using machine learning.

## 🚀 Live Demo

**Try TransitIQ here:** [Open Smart City Public Transport Optimizer](https://smart-city-transport-optimizer-bxjte98evfwcrrfjlb96vs.streamlit.app/)

Explore the interactive dashboard, analyze transport routes, investigate congestion patterns, and try the delay prediction feature.

## 📌 Project Overview

TransitIQ helps users explore transport data through interactive visualizations, route-level analysis, congestion insights, and machine-learning-based delay prediction. It combines data processing, analytics, and interactive maps in a single dashboard.

## ✨ Key Features

- **Overview Dashboard:** Explore key transport indicators and summary metrics.
- **Route Intelligence:** Analyze route-level transport performance.
- **Congestion Analysis:** Explore congestion patterns and potential traffic hotspots.
- **Delay Prediction:** Estimate transport delays using a machine learning model.
- **Model Insights:** Examine available model performance and insights.
- **Data Explorer:** Inspect the dataset and its underlying information.
- **Interactive Visualizations:** Explore charts and maps using Plotly and Folium.
- **Data Preparation:** Process and analyze data using Pandas and NumPy.

## ⚙️ Run Locally

### Prerequisites
- Python installed
- Git installed

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/thesatyam19/Smart-City-Transport-Optimizer.git
   ```

2. Navigate into the project directory:

   ```bash
   cd Smart-City-Transport-Optimizer
   ```

3. Create and activate a virtual environment (optional but recommended):

   ```bash
   python -m venv .venv
   ```

   Windows PowerShell:

   ```powershell
   .\.venv\Scripts\Activate.ps1
   ```

4. Install the project dependencies:

   ```bash
   pip install -r requirements.txt
   ```

5. Start the dashboard:

   ```bash
   streamlit run app.py
   ```

6. Open the local URL shown in your terminal.
